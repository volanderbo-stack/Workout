# Сила — тренування на тренажерах

Застосунок для силових тренувань вдома та в спортзалі, українською.

**Відкрити:** https://volanderbo-stack.github.io/Workout/

## Що вміє

- 185 вправ на всі групи м'язів, у залі переважно тренажери й блоки, з фото або схемою, налаштуванням тренажера, технікою й типовими помилками.
- Цілі: сила, гіпертрофія (маса), витривалість — підходи, повторення й відпочинок підлаштовуються автоматично.
- Готові комплекси, спліти й тижневий план Classic Physique.
- «Мої тренування»: власні шаблони за розподілом, журнал ваги й повторень, рекорди, історія та календар з групами м'язів.
- Таймер відпочинку зі звуком і вібрацією.
- Працює без інтернету та встановлюється на телефон.

## Як встановити на телефон

- **iPhone / iPad (Safari):** відкрий посилання → «Поділитися» → «На екран Додому».
- **Android (Chrome):** відкрий посилання → меню ⋮ → «Встановити застосунок».
- **Комп'ютер (Chrome, Edge):** значок встановлення в адресному рядку.

## Дані

Тренування, шаблони й обране зберігаються лише в браузері на твоєму пристрої. Щоб перенести їх на інший пристрій, відкрий «Мої → Дані»: збережи файл або скопіюй текст і встав його там.

Поділитися з родиною: «Головна → Поділитися з родиною» (посилання на застосунок) або кнопка «Поділитися з родиною» в будь-якому своєму тренуванні — людина отримає посилання й додасть тренування собі одним дотиком.

## Структура

- `index.html` — увесь застосунок (HTML, CSS, JS); дані вправ і комплексів — масиви `EXERCISES` і `PROGRAMS` на початку скрипту.
- `img/` — зменшені фото вправ.
- `manifest.webmanifest`, `sw.js`, `icons/` — встановлення та робота без інтернету.
